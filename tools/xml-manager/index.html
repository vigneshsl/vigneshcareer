🔎 What Is It?

This tool helps you check and clean XML files in a folder.

It can:

• Tell you if your XML files are correct or broken
• Make your XML files look clean and easy to read

🎯 Why Use It?

🔍 Find Errors

To find errors in your XML files

✨ Fix Look

To fix the look of XML files with proper alignment

📤 Ready to Share

To make sure your files are ready to use or share

✨ What Can It Do?

✅ Check if XML files are valid (not broken)
✅ Make XML files look neat with proper spacing
✅ Do both (check + format) together
📁 Save fixed files in a new folder automatically
😄 Shows clear success/fail messages with emojis

👣 How To Use It?

1

Start the Tool

Run the tool (just open it)

2

Tell It Where Your Files Are

It will ask: Where are your XML files?

👉 Copy-paste the full path of the folder and press Enter

3

Choose What You Want

It will ask what you want to do:

Press 1 → Check only
Press 2 → Format only
Press 3 → Do both
4

See the Results

You will see messages like:

✅ Valid: file is good
❌ Invalid: file has problems
✅ Aligned: file is cleaned and saved

📁 Where Are the Clean Files Saved?

If you choose format (2 or 3), new files are saved in this folder:

C:\Customization tool\Xml Formatter

Inside, a new folder is created with the current date and time in the name.

📝 Note: Your original files stay untouched! The tool creates new clean copies.

🧩 Common Problems & Fixes

❌ Folder not found
Check the path. Make sure it's typed correctly.
❌ No XML files found
Make sure the folder has .xml files.
❌ Invalid XML
The file may be broken. Open it in Notepad to check.
🛑 Folder didn't open at end
Open the folder manually from the saved location.
