🔎 What Is It?

This tool helps you rename all files in a folder easily.

It can:

• Change file names to uppercase, lowercase, title case, or proper case
• Make all your file names clean and consistent

🎯 Why Use It?

🧹 Clean Names

Make all filenames look nice and organized

⚙️ Standardize

Match a naming style for your files

⏱️ Save Time

Rename lots of files quickly

✨ What Can It Do?

✅ Rename all files in a folder
🔠 Choose UPPERCASE, lowercase, Title Case, or Proper Case
📁 Skips folders automatically
🖼️ Keeps file extensions safe (like .jpg, .txt, etc.)
😄 Shows success messages as it renames

👣 How To Use It?

1

Start the Tool

Run the tool (just open it)

2

Enter the Folder Path

It will ask: Where are your files?

👉 Copy-paste the full folder path and press Enter

3

Choose the Case Style

It will ask which style to apply:

Press 1 → Proper Case (e.g. "My File.txt")
Press 2 → UPPER CASE
Press 3 → lower case
Press 4 → Title Case (e.g. "My_File.Txt")
4

See the Results

You will see messages like:

✅ Renamed: "file.txt" to "File.Txt"
❌ Skipped: "Photos" (not a file)

📁 What Changes?

Only the file names are changed. The file contents stay safe.

Example:

Before: hello world.txt → After: Hello World.txt

🧩 Common Problems & Fixes

❌ Folder not found
Check the path. Make sure it’s typed correctly.
⚠️ No files renamed
Files may already be in the selected format.
❌ Invalid option
Enter only numbers 1, 2, 3, or 4 when choosing a case style.
🔒 Cannot rename
Make sure files are not open or set to read-only.

💡 Helpful Tips

📁

Keep Files Together

Put all files to rename in one folder
